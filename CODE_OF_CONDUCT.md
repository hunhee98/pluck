# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text is canonical; this file is a short pointer plus the
project-specific details below.

## In short

- Be respectful and patient. Assume good intent; disagree on technical
  substance, not on the contributor.
- Critique code, designs, and ideas — not people.
- Keep discussion welcoming for people new to retrieval, IR, Rust, or
  agentic tooling. "Beginner" questions are fine and useful.
- No personal attacks, demeaning language, or targeted hostility.
- Off-topic political or ideological debate is out of scope here.

## Scope

These standards apply in every project space: GitHub issues, pull
requests, discussions, commit messages, code comments, and any
community channel that identifies itself with this project.

## Reporting

If you witness or experience behavior that violates these standards,
contact a project maintainer privately. Reports are handled in
confidence. Retaliation against good-faith reporters is itself a
violation.

If the issue involves a maintainer, escalate to any other maintainer or
open a private issue rather than a public one.

## Enforcement

Maintainers may, in response to a substantiated report:

1. Issue a private warning.
2. Require a public or private apology.
3. Temporarily restrict participation (issue/PR commenting, etc.).
4. Permanently remove access.

The chosen response is proportional to the violation and informed by
the Contributor Covenant's enforcement guidelines.
